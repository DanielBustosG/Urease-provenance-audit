# Urease-provenance-audit
Reproducible code, curated data, trained model bundle, and domain-aware application for auditing library-provenance bias in cross-collection comparisons of urease inhibitors.

Abstract:
Reference-library comparisons are widely used in target-focused cheminformatics to characterize the chemical space occupied by bioactive compounds. However, the resulting separation may reflect differences in library provenance rather than target-related chemistry. Here, we quantify this effect using UI-Ref, a curated reference set of 1,218 compounds reported in urease assays from ChEMBL, BindingDB, and PubChem, with assay- and document-level provenance retained. Within this single target-focused col-lection, a random forest trained on 25 physicochemical descriptors predicted the depos-iting database with a ROC AUC of 0.954 (95% CI: 0.939–0.968) and the source publication with a median one-versus-rest AUC of 0.997. We define these values as an empirical provenance noise floor: the level of separation that can be achieved from prove-nance-related structure alone, even when all compounds belong to the same tar-get-focused collection. Under a conventional pairwise design, comparisons between UI-Ref and external reference libraries produced AUCs of 0.957–0.983. After property matching and publication-grouped cross-validation, however, the corresponding AUCs decreased to 0.760–0.838, all below the database-provenance noise floor. The comparison with a toxicological inventory, which showed one of the strongest apparent separations under the conventional design, yielded the lowest corrected AUC (0.760). Near-est-neighbor rankings changed after sample-size balancing, and the apparent overlap with approved drugs corresponded to a median nearest-neighbor Tanimoto similarity of only 0.355. Moreover, clusters in the joint chemical spaces were associated more strongly with source publication than with collection membership (adjusted mutual information: 0.814 versus 0.187). We therefore developed a revised classification cascade incorporating explicit label definitions, probability calibration, a pre-specified applicability domain, and conformal prediction. Between 92.8% and 97.0% of the compounds in each external library fell outside the applicability domain, and only 10.3% of an external screening cohort completed the cascade with an informative prediction. These findings demonstrate that library provenance can dominate cross-collection comparisons and should be ex-plicitly evaluated before chemical or biological interpretations are drawn. The curated data, analysis code, trained models, and domain-aware application are publicly available.
